# The Human Archive

A production-quality prototype for a digital humanities archive. This repository contains a Next.js + TypeScript + Tailwind prototype implementing the core experience described in the project brief.

Usage

1. Install dependencies: npm install
2. Run development server: npm run dev

Notes

- This is a prototype with local demo data in data/archives.json. The architecture isolates data loading in /lib so a real API can be integrated later.
- Fonts are imported from Google Fonts for the prototype; for a production build, consider hosting fonts or using licensed fonts.
